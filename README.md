# Apple of Fortune

ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub (وليس المجلد نفسه).

- `index.html` في الجذر
- مجلد `assets/` يحتوي الصور المستخدمة في اللعبة
- توجد نسخ من الصور في الجذر أيضًا لتفادي مشاكل اختلاف مسار الرفع

بعد الرفع فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).
